基准集质量门槛通过，负例分片 R@5 = 1.0。独立集 MRR 的微小变化来自三条用例的金标排名各后移或前移一位（indy-014 5→4，indy-058 2→3，indy-059 3→4），金标都仍在前 5 名。

首版把结构化字段直接加进索引后，独立集出现退步：R@5 0.9365、R@10 0.9683。分开测试后确认有两个原因：

- 嵌入文本以标题和原因/影响摘要开头，向量偏向机制措辞，而用户多按症状描述来查（indy-065 掉出前 30）。
- BM25 加入原因/影响/组件等字段后，近似主题的条目反超正确条目（indy-059）。

最终采用的方案：嵌入文本保持叙述原文，迁移条目沿用旧分类词，向量与切换前完全一致；BM25 只额外加入新旧编号、旧分类和标题。共测了 9 种组合，见 `fault_rag/parse.py:embed_text` 与 `fault_rag/index.py:bm25_text` 的注释。

## 2026-10-22 · 2097 快照的豁免更正与口语 query 诊断

快照：inference 2117、training 364（2a7e7ac）。门禁数字与 32b0831 记录一致：基准 1.0 / 1.0 / 1.0 / 0.9966；独立集 R@5 0.9365、R@10 0.9524、MRR 0.8602、nDCG 0.8827。

**更正 indy-014 的豁免理由。** 32b0831 把它记为"扩容前后两路都在 20 名外的弱 gold"。在 e6f9928 重建基线索引（数值与 `baseline_indy.json` 完全一致），按该题自己的 `repo=inference` 过滤测单路名次：

| indy-014 → INF-0700 | 4 / 9 / 17 | 5 / 9 / 18 | 13 / 28 / 44 |
| indy-065 → INF-1278 | 6 / 114 / 15 | 6 / 109 / 16 | 22 / 181 / 26 |

indy-014 基线时两路都在前 20 内，是扩容造成的真实退化，经用户确认改记为 `accepted_regression`。indy-065 只有不加过滤时两路才都 >20，保留 `weak_gold` 并注明存疑。`fix_list.json` 每条从此必须写 `kind`，规则见 AGENTS.md。门禁判定逻辑不变。

**口语 query 诊断要点：**

- 两路都在 20 名外的 gold 共 3 条：indy-014、065、062；基准集 0 条。口语类 query 约 25 条，R@10 未命中 2 条。
- 065、062 的症状原文其实在条目里（`effect.detail`），失败原因是 query 模糊、多个条目共享同一表面现象。
- MRR 相对基线下降 0.031，其中 67% 来自 indy-001、025（新条目挤占），口语两条只占 22%。
- BM25 的主要噪声来自跨词边界的低频中文 bigram（如 indy-001 的"始错"，df=1）。
- 单路对比（独立集）：纯 BM25 R@5 0.905 / MRR 0.820，纯向量 0.825 / 0.741，混合 0.937 / 0.860。BM25 是两路中更强的一路，不能去掉。

结论：手写同义词表能满足全部验收却无法泛化，门禁分辨不出它和真修复，不采用；症状单独成路有害，不采用。任何词表或改写资源都必须在不接触评测集的条件下生成，冻结后再用新写的题验证。后续实验：bge-m3 自带稀疏检索、交叉编码器精排、`--also` 多查询。
