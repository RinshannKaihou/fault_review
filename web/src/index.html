检索与生命周期因果图怎么配合工作

默认的检索与浏览视图在浏览器里运行关键词 BM25，勾选“关键词 + 语义”会加载 multilingual-e5-small（int8，约 135 MB，缓存在本地浏览器），两路名次用 RRF 融合。

生命周期因果图把全部故障映射到「训练 → 权重导出 → 推理服务 + 底层软硬件地基」的模块依赖图上：点看到异常的模块即可顺箭头倒推候选真凶、勾选已知环境条件排除无关分支，并可一键将缩小后的候选范围带回检索视图做关键词或语义排序。

命令行版 fault-rag 还会用交叉编码器重排前 30 名；需要最完整的召回时请用命令行版。
